## 怎么交（30 秒版）

1. 打开 https://github.com/Cloudies152/Binguin
2. 进到任务里写的**目标目录**（比如点 `Textures` → `Things` → `Building` → `Joy` → `Binguin`）
3. 右上 **Add file → Upload files**
4. 把画好的 PNG 拖进去 → 底部 **Commit changes**

> 目录不存在就自己建：上传页面里可以直接输入带斜杠的路径，GitHub 会自动建目录。
> **文件名一个字都不能错**（大小写敏感），否则游戏里认不到。

---

## 通用规格（所有任务都适用）

| 项 | 要求 |
|---|---|
| 格式 | **PNG** |
| 底色 | **透明**（alpha 通道） |
| 颜色空间 | RGBA |
| 方向 | 一般要 `_south` `_north` `_east` 三向 |
| ★ 西向 | **`_west` 不用画** —— 游戏自动镜像 `_east` |
| 命名 | **逐字照抄**任务表里的文件名 |

> 💡 **参考现成文件**：每个任务都写了一个"照抄这个"的现有文件。下载下来当尺寸/对齐模板最省事。

# ⛔ 不要做的事

### 1. 不要"顺手补全"标了「借原版」的贴图

[贴图需求总表](参考/贴图需求总表.md) 里有一类叫 **「借原版」**（59 条）。
那是**故意**让冰鹅族的大衣/头盔/子弹/炮弹长得和游戏原版一样 —— **不是缺图**。

看到"冰鹅族风雪大衣 借原版 `Parka/Parka`"就去画一件，**反而是错的**。

**只画标了「缺图」和「占位图」的。**

### 2. 不要改 `Defs/` 里的 XML

贴图和 XML 是绑定的（XML 里写着去哪找贴图）。
**你只管按指定文件名和路径放图**，XML 不用动。

如果确实要改（比如新增一个发型 def），先看 [铁规则](参考/铁规则.md)。

### 3. 不要改文件名的大小写

`Band_Keyboard.png` 和 `band_keyboard.png` 在游戏里是**两个东西**。逐字照抄。
