## 0. 先跑起来（10 分钟）

### 你需要

| 前置 | 说明 |
|---|---|
| RimWorld **1.6** | Steam 版 |
| **Harmony** | [Workshop 2009463077](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077) |
| **Humanoid Alien Races 2.0**（HAR） | [Workshop 839005762](https://steamcommunity.com/sharedfiles/filedetails/?id=839005762) |
| 可选：**Nals.FacialAnimation** | 面部动画。不装也能跑（Mod 会自动降级） |

### 装 Mod（不编译也能玩）

```bash
# 把仓库整个 clone 到 RimWorld 的 Mods 目录
cd "<你的Steam库>/steamapps/common/RimWorld/Mods"
git clone https://github.com/Cloudies152/Binguin.git Binguin_Race_Mod
```

> Mod 已经**自带编译好的 `Assemblies/Binguin.dll`**，clone 完直接进游戏勾选即可。
> 目录名必须是 `Binguin_Race_Mod`（`LoadFolders.xml` 按这个名字找）。

### 改了 C# 才需要编译

```powershell
cd Binguin_Race_Mod\Source
.\build.ps1
```

用的是 .NET Framework 自带的 `csc.exe`（**C# 5 语法**，别写 C# 6+ 的东西：不能用字符串插值 `$"..."`、不能用表达式体成员、不能用 `?.`）。

## 1. 交东西的方式

### 最省事：直接在 GitHub 网页上改

1. 打开 https://github.com/Cloudies152/Binguin
2. 找到要改的文件 → 右上角铅笔图标
3. 改完 → 页面底部写一句说明 → **Create a new branch and start a pull request**

> 贴图也能这样传：进对应目录 → **Add file → Upload files** 拖进去。

### 或者 fork + PR

```bash
git clone https://github.com/Cloudies152/Binguin.git
cd Binguin
git checkout -b art/band-instruments     # 分支名随意，看得懂就行
# ...改东西...
git add -A
git commit -m "画了 5 件乐器贴图"
git push origin art/band-instruments
```

然后去 GitHub 点 **Compare & pull request**。

### 不想碰 Git？

把文件按下面的**目录结构**整理好，压缩包发给作者（群里的 **冰鹅**）也行。
⚠️ 但**目录结构一定要对**，否则贴图挂不上。

## 2. 🎨 美术任务

### 通用规格

| 项 | 要求 |
|---|---|
| 格式 | **PNG，透明底** |
| 颜色空间 | RGBA（带 alpha） |
| 画布 | 见各任务（建筑/物品/武器一般 128×128 或 256×256；小人相关见下） |
| 方向 | 一般要 `_south` `_north` `_east` 三向。**`_west` 不用画**，游戏自动镜像 `_east` |
| 命名 | 必须和任务表里的文件名**逐字一致** |

### ⚠️ 先看这份自动生成的清单

**`_美术/冰鹅族_贴图需求总表.md`** —— 里面有**准确**的缺口清单（从实际文件扫出来的，不是手工维护的）。

它把贴图分成四类：

| 分类 | 含义 | 要不要画 |
|---|---|---|
| **有图（正式美术）** | 已经有正式图了 | ❌ 不用 |
| **占位图** | ★ 作者用脚本画的临时图，**要替掉** | ✅ **要画** |
| **缺图** | 没有，游戏里是粉红方块 | ✅ **要画** |
| **借原版** | 故意借用游戏原版贴图 | ❌ **绝对不要画** |

> ★★ **「借原版」的不要动！** 那些是**有意**让冰鹅族的大衣/头盔/子弹/炮弹长得和原版一样，
> 不是缺图。看到"大衣借原版"就去画一件，反而是错的。

## 3. 💻 程序任务

### 3.1 ⭐ 重置【自定义钓竿的穿刺技能】

**现状**：技能已实现，但效果/手感要重做。相关文件：

| 文件 | 作用 |
|---|---|
| `Source/Ability_BinguinRodSkills.cs` | `CompAbilityEffect_BinguinPierce` —— 穿刺效果本体 |
| `AdvancedFishing/Defs/02_RodsAndParts/Fishing_RodsAndParts.xml` | `Binguin_AbilityPierce` def、鱼钩 def、装配台 def |
| `Source/BinguinDefPatches.cs`（约 L1483 起） | 把 `Binguin_AbilityPierce` 挂到成品的直钩竿上 |

**当前设计**（`AdvancedFishing2_Binguin.xml` L313 的 description 原文）：

> 直钩：获得技能「穿刺」——对前方 10 格内所有敌人造成 **200% 于武器面板**的伤害，**冷却 10 秒**。

**已知实现要点（改的时候别踩掉）**：

1. **必须走 Ability 系统，不能用 `ThingDef.verbs`**
   给 `verbs` 挂东西会让武器被判定成**远程武器**（早期踩过："鱼竿变远程武器"）。
   正确路线：装备时 `CompBinguinRod.Notify_Equipped` → `pawn.abilities.GainAbility` →
   `AbilityTracker.GetGizmos` 显示按钮。

2. **`Valid` / `CanApplyOn` 必须 override 返回 `true`**
   基类对特定子类型做硬 cast，不 override 会 `InvalidCastException`
   （日志里表现为 `Root level exception in OnGUI`）。

3. 伤害吃 `StatDefOf.MeleeDamageFactor`（技能/特质加成要正常生效）。
4. 目标筛选：不打自己/友军/盟友，且 `GenSight.LineOfSight` —— **不隔墙斩人**。

**重置方向建议**（等作者确认最终规格）：

- [ ] 手感/特效重做（现在是脚下尘土 + 直线冰屑拖尾）
- [ ] 是否需要**穿透多个目标**、还是"前方一条线全中"
- [ ] 冷却/耗蓝/次数是否调整
- [ ] 是否要和弯钩的「钩鱼」技能做统一的手感

### 3.2 ⭐ 重置【制作钓竿的 UI】

**现状**：现在有**两套并存的入口**，都从装配台的 gizmo 进：

| 入口 | 代码 | 交互 |
|---|---|---|
| **地图点选 4 次** | `Source/RodPartPicker_Binguin.cs` | 打开装配台 → 在地图上依次点选 竿身→竿头→鱼钩→鱼饵，每步只高亮该类物品 |
| **库存选件窗口** | `Source/Dialog_BinguinRodStockPick.cs`<br>+ `Source/RodPartStock_Binguin.cs` | 一个窗口里 4 个槽位，每槽「更换」→ 弹出该类候选列表；下面选殖民者；底部「开始装配」 |

还有几个**保留但当前没接上**的对话框，可以当参考：

| 文件 | 说明 |
|---|---|
| `Source/Dialog_BinguinRodAssembly.cs` | 按材质精确列 4 类配件 + 选制作人 + 属性预览（**当前被注释掉，没用到**） |
| `Source/Dialog_BinguinRodWorkerPick.cs` | 第 5 步「选谁来装配」 |
| `Source/Dialog_BinguinResumeRodAssembly.cs` | 半成品「继续装配」选人 |
| `Source/Dialog_BinguinBait.cs` | 制作鱼饵（选 1~2 种食材效果） |

**★ 改之前必须知道的坑**：

1. **不要用 `Find.Targeter.BeginTargeting` 连续链式弹下一个 targeter**
   `Targeter.StopTargeting()` 的 IL 是**先调回调、再清字段** ——
   你在 `actionWhenFinished` 里刚设好的 `targetParams` 会被立刻清空 ⇒ 没圆圈。
   6 参数重载不接受 validator；5 参数重载会把 `Targeter.targetValidator` 置 null，
   而 `ProcessInputEvents` 在 `targetingSource == null` 时判的就是这个字段。
   （详见 `RodPartPicker_Binguin.cs` 顶部那段"三次踩坑记录"）

2. **"选人"这一步用窗口，不要用地图点选**（同上原因）。

3. **配件分类规则在两处重复，改一处要改两处**：
   `RodPartPicker_Binguin.Steps` 和 `RodPartStock_Binguin` 里的分类列表。
   顺序固定：竿身 → 竿头 → 鱼钩 → 鱼饵。
   ```
   竿身：Binguin_RodShaft_Long / Binguin_RodShaft_Short
   竿头：Binguin_RodTip_Blade  / Binguin_RodTip_Hammer
   鱼钩：Binguin_RodHook_Straight / Binguin_RodHook_Curved
   鱼饵：Binguin_RodBait（只有一种）
   ```
   扫描范围是**整个地图**的 `ThingRequestGroup.HaulableEver`（不做储存区/距离过滤）。

4. **半成品装配的续接逻辑**在 `Comp_BinguinUnfinishedRod.cs`（34 KB，最复杂的一个），
   里面有 `stallTicks` 看门狗（`StallResetTicks = 600`）。改装配流程前先读这个文件的注释。

**重置方向建议**（等作者确认最终规格）：

- [ ] 两套入口**合并成一套**（现在是两条路并存，容易混淆）
- [ ] 排版/操作步骤重做
- [ ] **配件「搬上台」动画**（现在配件是 `FinishAssembly` 里直接 `Destroy` 消失，
      小人只是走到台前工作，**没有真的把东西搬到台上摆出来**）
- [ ] 装配时**手选制作人**（现在是自动挑制作技能最高者，不能手点）

## 4. 🌏 翻译任务

### 现状

- 中文（基准）：`Languages/ChineseSimplified/Keyed/Binguin.xml` —— **603 个键**
- 英文：`Languages/English/Keyed/Binguin.xml` —— **603 个键**（已全部翻译完）
- 英文 def 文案：`Languages/English/DefInjected/<类型>/BinguinTranslation.xml` —— 28 个文件

中英键集合必须**完全一致**。

### 怎么加/改文案

**不要直接改 C# 里的中文字符串** —— 那些不经过本地化，改了只影响中文。
正确做法：

1. 在 `Languages/ChineseSimplified/Keyed/Binguin.xml` 加键：
   ```xml
   <Binguin_你的键名_01>中文文案</Binguin_你的键名_01>
   ```
2. 在 `Languages/English/Keyed/Binguin.xml` 加**同名键**，值写英文
3. C# 里用 `"Binguin_你的键名_01".Translate()`
   ⚠️ **`Translate()` 返回 `TaggedString`，不是 `string`**。要传给
   `Messages.Message(string, ...)` 或放进三元表达式，必须先 `.ToString()`（否则编译报 CS0172）

### 想要别的语言

复制 `Languages/English/` 整个目录，改名成目标语言（如 `Languages/Japanese/`），
翻译 `Keyed/Binguin.xml` 与 `DefInjected/` 里的 `<label>` / `<description>` 即可。
**键名不要动。**

## 5. 必须遵守的规则（会弄坏 Mod 的坑）

### ⛔ ① XML 里**绝对不能**出现自定义类型名

**不要**在任何 XML 里写 `compClass` / `driverClass` / `workerClass` / `giverClass`
指向本 Mod 的 C# 类。HAR 加载顺序会让这些类找不到，报红字。
本 Mod 全部靠 C# 里 `[StaticConstructorOnStartup]` 的 `SafePatch` 从代码注入。
**看到的 XML 里没有自定义类型名，那是故意的，别"帮忙补上"。**

### ⛔ ② 不要用 `Harmony.PatchAll`

`PatchAll` 在这个 Mod 里会崩。用显式的 `SafePatch`（见 `BinguinMod.cs`）。

### ⛔ ③ 贴图不要"顺手补全"

见 [任务总表](#-先看这份自动生成的清单) —— **「借原版」的贴图是有意借的**，
补了反而破坏设计。只画清单里标「占位图」和「缺图」的。

### ⛔ ④ 不要改数值/玩法平衡

伤害、造价、工作量、概率这些**要先问作者**。改贴图和 UI 随便改。

### ⛔ ⑤ 别覆盖别人正在编辑的文件

改之前先 `git pull`。文案类文件作者可能同时在改。

## 6. 名词对照表

| 术语 | 意思 |
|---|---|
| **HAR** | Humanoid Alien Races 2.0，外星人框架，本 Mod 的前置 |
| **FA / Nals.FacialAnimation** | 面部动画 Mod，管眼睛/眉毛/眼皮/嘴的分层渲染 |
| **defName** | RimWorld 里每个东西的唯一 ID（如 `Binguin_FishingRod`） |
| **texPath** | XML 里指向贴图的路径（**不带扩展名**，`Textures/` 是根） |
| **DefInjected** | 语言文件，按 `DefName.字段` 覆盖 def 的 label/description |
| **Keyed** | 语言文件，给 C# 里 `"...".Translate()` 用的键值对 |
| **BodyType** | 体型（Male/Female/Thin/Fat/Hulk/Child/Baby…） |
| **graphicPaths** | HAR 里覆盖身体/头部贴图的配置段 |
