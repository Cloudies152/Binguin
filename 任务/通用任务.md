# 任务 1 ★：试玩找 bug

## 怎么帮忙

1. 按下面清单开一局，**一项一项试**
2. 发现不对的：**截图 + 描述"我做了什么 → 期望什么 → 实际什么"**
3. 发到群里，或在 GitHub 开 [Issue](https://github.com/Cloudies152/Binguin/issues)
4. 如果知道怎么复现（重开一局还会出现吗？），一定写上

> 💡 **带上 `Player.log` 更有用**（有报错的话）：
> `%USERPROFILE%\AppData\Local\Low\Ludeon Studios\RimWorld by Ludeon Studios\Player.log`
> 直接搜 `[冰鹅族]` 或 `Exception` 就能看到我们 Mod 的日志。
