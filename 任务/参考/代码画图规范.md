# 🖌️ 代码画图规范（AI 软件手绘）

> 这份文档给"用代码/矢量直接画"的贴图用（不是 AI 生图）。
> 目标：**每一张都结构正确、比例统一、边缘锐利、配色一致**，不用反复试。

---

## 0. 什么时候用代码画

| 情况 | 用代码 | 用 AI 生图 |
|---|---|---|
| 图标 ≤128px（炮塔顶部、物品、UI） | ✅ | ❌ 必糊 |
| 需要精确结构/比例（枪械、炮塔） | ✅ | ⚠️ 会擅自改结构 |
| 需要"画布对齐/轴心"（炮塔旋转） | ✅ | ❌ |
| 需要质感、创意、大量细节 | ⚠️ 费时 | ✅ |

**结论：本 mod 的物品类贴图，默认代码画。**

## 1. 画布与坐标

| 资产 | 画布 | 说明 |
|---|---|---|
| 枪械 | 256×128 | 枪口朝右，居中留 4px 边 |
| 炮塔顶部 | 小 128×128 / 大 192×192 | **以画布中心为旋转轴** |
| 物品 | 128×128（小件 64） | 居中 |
| 建筑 | 按占地 64/128/192 | — |

**超采样**：先用 `S=4`（或 8）在 `W*S × H*S` 上画，最后 `resize(W,H, LANCZOS)`。这样 1px 描边不会锯齿。

## 3. 线条与形状规则

- 描边：**1.5–2.6px**（按尺寸），颜色 `#101216`，圆角 `radius≈2–4px`
- **不要**渐变、阴影模糊、噪点、写实纹理
- 圆角只做"一点点"（2–4px），别做成胶囊
- 暗部/阴影**只能放在尾部**（远离枪口的反方向），因为炮塔会 360° 旋转
- 所有部件尽量共用**一条中轴**，枪口端**齐平**

---

## 4. 结构模板

### 4.1 枪械（侧面，枪口朝右）
```
[枪托/尾部] — [机匣（含握把、扳机护圈）] — [护木/导轨] — [枪管] — [枪口装置]
                     ↑ 顶部：瞄具/提把        ↑ 下方：弹匣
```
比例参考：整长 200–240px（画布 256），机匣约占 1/3，枪管占 1/4。

### 4.2 炮塔顶部（俯视，炮管朝右）
```
[尾部机械件（比机身细一圈）] — [机身（带高光带）] — [管簇] — [枪口]
```
- 六管环排 → **俯视只画 3 根**：上下两根在下层，中间一根压在上面
- 三根必须**等粗、等距、枪口齐平**

### 4.3 物品
```
[主体大形] + [1–2 个识别特征] + [高光]
```
形状数控制 **4–8 个**，不要碎细节。

---

## 5. 分层顺序（从下到上）

1. 挂件/附件（弹链、支架）——会被主体压住的部分先画
2. 主体大形（机身）
3. 结构分块（护木、导轨、弹匣、握把）
4. **横向高光**（见 §6）
5. 细节（散热槽、镜环、箍）
6. 外描边（最后再描一遍，保证边缘干净）

---

## 6. 横向高光（统一光照）

机身中线最亮，向上下渐隐、向两端淡出：

```python
yy, xx = np.mgrid[0:h, 0:w]
a = (np.exp(-((yy-cy)/(h*0.26))**2) * np.exp(-((xx-cx)/(w*0.62))**2) * peak)
```
- `peak`：炮塔 95–110，武器 60–80（别太亮）
- 用**圆角矩形蒙版**裁剪，只落在机身内
- 画在描边**之前**，避免糊掉轮廓

## 7. 常见错误 → 改法

| 错误 | 现象 | 改法 |
|---|---|---|
| 多根管贴太近又同色 | 糊成一整块黑色板砖 | 管间留 2–4px 间隙，每根各画顶部高光，中管单独压上 |
| 枪管太长太黑 | 像一根棍子 | 缩短管长、加枪口环、加中段箍 |
| 暗部在下缘 | 旋转后"底部"永远朝下 | 暗部移到**尾部** |
| 部件不同轴 | 看起来歪 | 所有 y 基于同一个 `CY` 计算 |
| 枪口端参差 | 右侧像锯齿 | 所有管 `x1` 统一 |
| 缩到 128 糊 | 边缘灰 | 用 `S=4` 超采样 + LANCZOS；不要先画小再放大 |
| 细节碎 | 32px 看不清 | 形状数 ≤8，线宽 ≥1.5px |

---

## 8. 交付前质检

1. **三档目视**：256 / 128 / 32px 都能看清主体
2. **并排对比**：和同系列 2–3 张放一起，色相/线宽/比例一致
3. **轴心检查**：炮塔类画一条中轴，看是否对称
4. **透明检查**：alpha 边缘无白边（抠底要留 1px 羽化）
5. 进游戏后：`Tools/Deploy-BinguinToGame.ps1` → 确认 `SAME=True`

## 9. 代码模板（PIL）

```python
from PIL import Image, ImageDraw
import numpy as np

S = 4                      # 超采样倍数
W, H = 256, 128
img = Image.new("RGBA", (W*S, H*S), (0,0,0,0))
d = ImageDraw.Draw(img)

BLACK=(16,18,22,255); GRAYBLUE=(64,76,89,255)
BLUE=(103,132,155,255); DARK=(15,19,24,255); WHITE=(224,229,234,255)

def rr(x0,y0,x1,y1,fill,r=2.0,outline=BLACK,w=2.0):
    d.rounded_rectangle([x0*S,y0*S,x1*S,y1*S], radius=r*S, fill=fill,
                        outline=outline, width=int(w*S) if outline else 0)

# 横向高光
def sheen(box, radius, peak=80, color=(214,216,220)):
    x0,y0,x1,y1 = box
    w,h = int((x1-x0)), int((y1-y0))
    cx, cy = w/2, h/2
    yy, xx = np.mgrid[0:h, 0:w]
    a = (np.exp(-((yy-cy)/(h*0.26))**2) * np.exp(-((xx-cx)/(w*0.62))**2) * peak).clip(0,255).astype(np.uint8)
    layer = Image.new("RGBA",(w,h), color+(0,)); layer.putalpha(Image.fromarray(a,"L"))
    mask = Image.new("L",(w,h),0); ImageDraw.Draw(mask).rounded_rectangle([0,0,w-1,h-1], radius=radius, fill=255)
    layer.putalpha(Image.composite(layer.getchannel("A"), Image.new("L",(w,h),0), mask))
    img.alpha_composite(layer, (int(x0), int(y0)))

img.resize((W,H), Image.LANCZOS).save(r"...\out.png")
```
