## 3. 色板（必须沿用）

| 名称 | HEX | 用途 |
|---|---|---|
| 外描边黑 | `#1A1A1A` | 只有**整枪外轮廓**一圈 |
| 深灰壳体 | `#3A424A` | 主结构，约 60% 面积 |
| 浅灰镶板 | `#E8ECF0` | 顶面/镶板，约 25% |
| 机械结构蓝 | `#4888B2` | 握把、支脚 |

## 4. 必须保留的原型特征

1. 左侧**斜切主握把 + 宽方块底座**
2. 机匣左上方**矮扁瞄具仓**
3. 机匣**上下双层能量槽**
4. 向右**超长护木**，下沿一排等距指示灯
5. 最右端**短竖方块**（不是收尖枪管）
6. 机匣下方**两个并排支脚**

---

## 5. 画法要点（关键，决定像不像 DP-12）

1. **先画一条闭合剪影**（整枪外轮廓，含握把/支脚）→ 填 `#3A424A`，**先不加描边**
2. 在壳体上**挖孔**（能量槽、指示灯、扳机圈）→ 路径查找器【减去顶层】，仍是复合路径
3. **附着件**（枪管、导轨、瞄具）叠在上层，不参与布尔
4. **转折线**只画结构折角（1.5pt），不跟着色块走
5. **高光** ≤4 条，只在大面，2~4px 高
6. **最后**复制剪影路径 → 只描 3pt 黑边（不要给形状本身加描边，否则孔边也带粗黑边）

**圆角**：主壳 4pt / 小件 2pt / 孔 1pt / 槽内 0

**禁止**：每个零件单独描边、均等间距的网格细节、大面积能量蓝铺在表面、渐变和模糊。

## 6. 自检

- [ ] 眯眼看：是不是"一把枪"，不是"一堆方块"
- [ ] 数粗黑框：只有**一整圈**
- [ ] 高光 ≤4 条
- [ ] 蓝色面积 ≤ 深灰面积 25%
- [ ] 缩小到 64px 仍能认出是枪
