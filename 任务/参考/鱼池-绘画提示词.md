# 冰鹅族 · 鱼池贴图 绘画提示词（新版：只画岸边）

> 给 AI 绘画 / 画师用。**注意：水面不再画进贴图里**，全部交给游戏渲染。

---

## 一、关键变化（请先读）

| | 旧版 | **新版** |
|---|---|---|
| 贴图画什么 | 水里 + 岸边石 | **只有岸边石** |
| 中间水面 | 我们自己画 | **透明，留空** |
| 为什么 | — | 游戏会把鱼池格子换成**原版水地形**，由游戏自己的水体着色器渲染 |

所以：**中心必须是完全透明的**，画进去的任何水都会被盖住/穿帮。

---

## 二、这是什么

RimWorld 1.7 模组「冰鹅族」的**鱼池建筑**贴图。

- 鱼池是 **2×2 格**的建筑，玩家可以把多个鱼池拼在一起（水面连成一片）
- 贴图按「四边哪几边连着别的鱼池」分成 16 种，连上的那一边**不画岸边石**
- 美术只需要画 **6 种基本形状**，其余由脚本旋转生成

## 四、画面要求

### 尺寸
- **建议画 1024×1024**（我缩到 128），正方形，四边严格对齐，**不要羽化/渐变边**
- 岸边石带宽 ≈ 图宽的 **11%**（1024 时约 112px）

### 内容
- **只有池壁 / 岸边石**：一圈厚边 + 四角有角落石
- **中间完全透明**（不要画水、不要画水面波纹、不要画水底）
- 池壁要**从上方俯视**的厚度感：外沿深色描边、内侧一道亮面、再内侧一道暗面

### 画风（与原版/本模组统一）
- **扁平矢量、纯色平涂**
- 外轮廓 **粗黑描边**（约 11px @1024），内部结构线细一些
- 右上单向硬高光、右下硬阴影
- **无渐变、无写实、无透视、无发光**

## 六、直接可用的提示词

### 通用前缀

```
游戏建筑贴图，俯视图，扁平矢量风格，纯色平涂，粗黑描边（外轮廓粗、内部结构线细），
右上硬边高光、右下硬阴影；无渐变、无透视、无模糊、无发光。
1024×1024，正方形，背景全透明，画面无文字。
配色只用：#02040A 描边、#2D374B 暗面、#424D61 主色、#576478 亮面、#8291A5 角落石、#C7C9D5 高光。
```

### 1）四面都有岸（pond_0）

```
画一圈方形水池的池壁：四条边都有厚实的石砌池壁，四角各有一块方形角落石；
池壁外侧深色描边、中间一层灰蓝石材、内侧一道亮面；
中间区域完全留空（透明），不要画水。
```

### 2）上侧开口（pond_1）

```
同上，但上边不画池壁（开口），只剩左、右、下三面池壁；上边两角保留角落石的一半。
```

### 3）上+右开口（pond_2adj）

```
同上，但上边和右边都不画池壁，只剩左边和下边两面（L 形）；右上角没有角落石，其余三角保留。
```

### 4）上+下开口（pond_2opp）

```
同上，但上边和下边不画池壁，只剩左边和右边两面平行池壁；四个角落石保留一半。
```

### 5）只有左侧有岸（pond_3）

```
只画左边一面池壁，其余三面开口；左上、左下两个角落石保留。
```

### 6）四面开口（pond_4）

```
不画池壁，只在四个角落各画一块方形角落石（其余全部透明）。
```

## 七、自检

1. 中间是不是**完全透明**？（放进棋盘格看，不能有任何水色）
2. 开口方向对不对？（`pond_1` 开口朝上、`pond_2adj` 朝上+右……）
3. 四边的池壁厚度一致吗？（拼起来不能有错位）
4. 有没有渐变、发光、蓝色水面？
5. 缩到 128×128 后，池壁还看得出来吗？

---

## 八、为什么不画像素

旧版是**程序直接生成 128×128 的方块图**（硬边、纯色块），看起来像像素图，那是为了对齐格子、省事。

新版请按 **1024×1024 的矢量风格**画，细节和描边自然度都会好很多，最后由脚本缩到 128 写进游戏。
