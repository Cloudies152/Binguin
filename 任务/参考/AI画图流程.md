# 🎨 AI 画图流程与画风规范

> 面向"用 AI 生成 + 代码修图"的流水线。目的：**以后每张图都能一次画到位，不用来回试**。
> 适用于武器、炮塔、物品、建筑图标等**物品类贴图**；小人/衣服不在此文档范围（已约画师）。

---

## 0. 结论先行（先记住这 5 条）

1. **小图标（≤128px）优先代码画**，AI 生成的边缘在缩小后必糊。
2. **AI 图必须给两张参考**：①结构参考（线稿/实拍/上一版）②画风+配色参考。
3. **每次生成前刷新页面**——即梦的参考图会累积，越堆越跑偏。
4. **配色一律取色**，不要靠文字描述"蓝一点白一点"；取色比例写进提示词。
5. **描边/色块**必须要求"粗黑描边、扁平色块、无渐变、无噪点"。

---

## 1. 统一画风规范

| 项 | 规范 |
|---|---|
| 风格 | 扁平矢量（flat cel），色块平涂 |
| 描边 | 近黑 `#101216`，**粗**（128px 图上约 1.5–2px） |
| 禁止 | 渐变、写实纹理、噪点、投影方向性阴影（炮塔会 360° 旋转） |
| 背景 | 纯白（后处理会抠掉） |
| 朝向 | 武器/炮塔：**枪口朝右** |

### 1.1 武器配色（以 DP-12 取色为基准）

| 色 | 色值 | 占比 |
|---|---|---|
| 灰蓝（机匣主体） | `#404C59` | ~38% |
| 近黑（枪管/描边） | `#0F1318` | ~28% |
| 中蓝（护木/握把/弹匣） | `#67849B` | ~19% |
| 白（顶面高光块） | `#E0E5EA` | ~15% |

> ⚠️ 白色只用在**小面积**，大片白会显得"没上色"。

### 1.2 炮塔配色（照原版炮塔取色）

| 部位 | 小炮塔（霰弹） | 大炮塔（加特林） |
|---|---|---|
| 机身 | 土黄 `#706040` | 深灰 `#4A4A4A` + 橄榄带 `#506050` |
| 枪管 | 灰 `#808080` | 深灰 `#4A4A4A` |
| 机械件 | 灰 `#606060` | 深灰 `#343434` |
| 枪口 | 近黑 `#1E2024` | 近黑 `#1E2024` |
| 描边 | `#101216` | `#101216` |

### 1.3 尺寸表

| 资产 | 画布 |
|---|---|
| 枪械 | 256×128 |
| 炮塔顶部 | 小 128×128 / 大 192×192 |
| 物品 | 128×128（小件 64×64） |
| 建筑 | 64/128/192 宽（按占地） |

## 2. 两条产线（先选对工具）

### A. 代码绘制（PIL / Illustrator）——**小图标首选**
- 优点：像素级精确、**永不糊**、0 成本、随时改坐标
- 适用：炮塔顶部、物品图标、UI 图标、任何 ≤128px 的东西
- 现成脚本：`Tools/ai_*.jsx`（Illustrator 线稿）、`Tools/Make-Binguin*.ps1`（批量生成）

### B. AI 生图（即梦 Seedream 5.5 / 智谱 CogView）——**需要"质感/创意"时用**
- 优点：造型、材质、构图有想象力
- 缺点：**边缘是软的**，缩到 128 必糊；会擅自改结构
- 适用：256×128 的枪械、需要风格化的建筑
- 成本：即梦 4 积分/张（≈¥0.18）；智谱 CogView-4 ¥0.06/张（带水印，需裁）

> 📌 经验：**炮塔这种小图标用 AI 反而更差**——出图 480×204，缩到 128 全是灰边。后来全部改成代码画。

## 3. 即梦标准流程

### 3.1 环境
- 浏览器：Edge，`--remote-debugging-port=9222 --user-data-dir=W:\dsh\zengbing\Tools\edge_jimeng_profile`
- 启动脚本：`Tools/jimeng_open.py`（会轮询登录状态并写 `jimeng_login.ok`）
- 连接：Playwright `connect_over_cdp("http://127.0.0.1:9222")`

### 3.2 操作序列（脚本必须按这个顺序）
1. `page.goto(生成页)` → 等 5–7 秒
   **① 必须先刷新**，否则上一轮的参考图还挂着
2. 上传参考图：**只能拖拽**（`DragEvent` + `DataTransfer` + `File`），点击不会弹文件选择框
   - 第一张 = 结构参考，第二张 = 画风/配色参考
3. 填提示词：`div[contenteditable='true'][aria-label='提示词']`，用 `keyboard.insert_text`
4. 张数：点"4张"→ 选 `radio` 里的数字（1 张最省）
5. 生成按钮：`lv-btn-primary` + 圆形 + 宽 < 40 的那个，用 `evaluate("e=>e.click()")`
6. 抓结果：轮询 `img[src^="http"]` 的新增项（4 张约 20–40 秒）
7. 下载：页面 `fetch` 会被 secsdk 拦，**必须用** `context.request.get(url, headers={"Referer": "https://jimeng.jianying.com/"})`

### 3.3 提示词模板

**枪械**
```
第一张是结构参考：<型号>（<结构要点>）。第二张是画风配色基准。
扁平色块、粗黑描边、内部不画线、不要渐变。
配色：灰蓝(#404C59)机身、中蓝(#67849B)护木/握把、近黑(#0F1318)枪管与描边、白(#E0E5EA)小面积。
纯白背景，侧面视角，枪口朝右，居中，无文字。
```

**炮塔顶部（若用 AI）**
```
第一张是原版<塔>顶部（画风/配色/朝向基准）。
保持：炮管朝右、<部件结构>、配色沿用原图（<色值>）。
不要方向性阴影、不要圆弧、纯白背景、居中。
```

**物品**
```
第一张是结构线稿：<物品>（<结构要点>）。
第二张是画风基准。扁平色块、粗黑描边、不要渐变、细节不超过 8 个形状。
纯白背景，居中，无文字。
```

## 4. 后处理流水线

1. **抠白底**：从四边 flood fill 近白像素（tol ≈ 22）→ alpha=0
2. **去水印/杂物**：取**最大连通区域**（智谱的"AI生成"角标靠这个裁掉）
3. **裁切**：alpha bbox
4. **缩放**：
   - 大图 → 目标尺寸用 `LANCZOS`
   - 小图标要"硬边"：先 `quantize(colors=12)` 再 `NEAREST` 缩放
5. **居中放置**到目标画布（透明）
6. **验证**：128 / 48 / 32 px 三档目视检查，细节不能糊成一团

## 5. 常见问题 → 对策

| 现象 | 原因 | 对策 |
|---|---|---|
| 越画越偏 | 参考图累积 | 每次生成前刷新页面 |
| 结构被改（枪管变短、多个零件） | 只有一张参考 | 结构参考 + 画风参考**两张**，并在提示词里逐条写"必须保留" |
| 缩小后糊 | AI 边缘软 + 下采样 | 小图标改代码画；或 quantize + NEAREST |
| 颜色跑偏（整体土黄/全蓝） | 只写"蓝白" | **给色值 + 占比**，并说明白色只占小面积 |
| 出现方向性阴影 | 默认光照 | 明确写"不要方向性阴影"，暗部放**尾部** |
| 图里有"AI生成"角标 | 智谱免费版水印 | 最大连通域裁切 |
| 炮管"歪" | 枪口端参差 / 部件不同轴 | 所有部件共用一条中轴，枪口齐平 |
| 生成失败/积分不足 | 余额不够 | 先读页面余额；4 积分/张 |
