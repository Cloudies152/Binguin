# 冰鹅族 鱼池贴图 · 母版规格（只需画 6 张）

> 鱼池在游戏里用到 **16 张**连接变体，但**只需要画 6 张母版**，
> 其余 10 张由脚本按 90° 旋转自动生成（运行时代码不用改）。

---

## 一、为什么是 6 张

16 种连接组合按"整体旋转 90° 等价"合并，只剩 6 种形状：

| 文件名 | 形状 | 开口（不画岸边石的那几侧） |
|---|---|---|
| `pond_0.png` | 四面都有岸边石 | 无 |
| `pond_1.png` | 只有一侧没岸 | **上（N）** |
| `pond_2adj.png` | 相邻两侧没岸（转角） | **上 + 右（N+E）** |
| `pond_2opp.png` | 相对两侧没岸（直通） | **上 + 下（N+S）** |
| `pond_3.png` | 只有一侧有岸 | **上 + 右 + 下（N+E+S）** |
| `pond_4.png` | 四面都没岸（纯水面） | 全部（N+E+S+W） |

> 开口方向按上表来，**不要自己换方向**——脚本靠这个对应关系做旋转。

---

## 二、尺寸与画法

- **尺寸**：128×128（或 256×256 出图，我缩回 128）
- **必须正方形、四边对齐**（旋转后要能无缝衔接，边缘不能有渐变羽化）
- **岸边石带宽**：约图宽的 **11%**（128px 时约 14px）
- **水面**：中间区域，带 2~3 道浅色波纹
- **角落石**：四角有小石块的深色收角（`pond_0` 四个角都要有）

---

## 三、配色（从现有贴图取样，可直接用）

| 部位 | HEX |
|---|---|
| 水面主体 | `#285A96` |
| 浅色波纹 | `#4682BE` |
| 岸边石 | `#424D61` |
| 岸边石内沿（更暗） | `#2D374B` |
| 角落石 | `#8291A5` |

画风要求：**纯色平涂 + 粗黑描边**，和武器的画风统一（外轮廓约 2px 深色）。

---

## 四、旋转对称要求（很重要）

因为 10 张变体是**旋转母版**得到的，所以：

1. **水面纹理要接近四向对称**（波纹不要太有方向性），否则旋转后明暗方向不一致，拼在一起会"打补丁"
2. **光照要均匀**：不要画明显的左上高光 / 右下投影（旋转 90° 后高光会跑到别的边）
3. 岸边石的**剖面形状要四边一致**（上边和右边的石头形状不能不同）

---

## 五、生成方式

```powershell
python Tools/gen_pond_from6.py <母版目录> <输出目录> 128
```

会输出 `FishPond_l0.png` … `FishPond_l15.png` 共 16 张，覆盖到：

```
Textures/Things/Building/Binguin/
```

对应关系（脚本内固定）：

```
l0  ← pond_0
l1  ← pond_1 旋转0°      l2 ← 90°   l4 ← 180°   l8 ← 270°
l3  ← pond_2adj 旋转0°   l6 ← 90°   l12 ← 180°  l9 ← 270°
l5  ← pond_2opp 旋转0°   l10 ← 90°
l7  ← pond_3 旋转0°      l14 ← 90°  l13 ← 180°  l11 ← 270°
l15 ← pond_4
```

---

## 六、验收

1. 6 张母版单独看都是"一个完整水池"
2. 旋转 90° 后，岸边石仍然对齐、没有错位缝隙
3. 缩到游戏尺寸（2×2 格）看，水面和岸边石对比清楚
4. 颜色只用上面 5 个色
