## 一、这是什么项目

游戏里这些图标的显示尺寸很小（背包里约 40px 高、信息卡约 80px），所以**画面必须"缩到很小也一眼认得出是什么"**。

## 二、画风基准（很重要）

看 `05_画风基准_激光机枪.png`：这是本模组已经定稿的武器画风，**所有物品图标都要跟它一致**。

特征：

1. **扁平矢量、纯色平涂**——不要渐变、不要渐变阴影、不要高斯模糊、不要发光晕染
2. **粗黑描边**：外轮廓粗（约图高 3%），内部分割线细（约 1.5%）
3. **右上单向硬高光**（一条窄长浅色带），**右下硬阴影**（深色窄带）
4. **正侧视、无透视**：卷线器画成**正圆**（不是椭圆），导线环**侧着看**（不是正对镜头）
5. 纯白背景（透明底更好），无文字，**枪/竿尖朝右**

---

## 三、鱼竿的结构规则（必须遵守）

看 `08_结构示意.png`，逐条对照：

1. **竿身是弯的**：从握柄向上弯出一道弧线，不是直杆
2. **握柄 + 卷线器**在左下：卷线器是**正圆**，中心有轴点，侧面一个**摇柄**
3. **导线环**：沿着竿身下沿挂 **2~3 个**，画成**侧视的小环**（窄长的小圈，环面与视线平行），不是大正圆
4. **钓线**：从卷线器引出，**依次穿过每个导线环的孔洞**（关键！不能从环外绕过去），一直走到竿尖顶环，再垂向右下方
5. **鱼钩**挂在钓线末端（一个小 J 形钩）
6. **最后一个导线环**必须在**竿尖配件的下方**（装刀/装锤时尤其要注意）

## 四、配色（只用这 8 个色）

看 `09_鱼竿配色.png`。这是从现有鱼竿贴图统计出来的实际用色，**不要引入其他颜色**：

| HEX | 用途 | 占比 |
|---|---|---|
| `#040507` | 描边黑 / 最暗 | 18% |
| `#1E212A` | 深灰 阴影 | 14% |
| `#323844` | 深灰 主体暗部 | 16% |
| `#4E5364` | **灰蓝 主体** | 20% |
| `#667588` | 灰蓝 亮面 | 9% |
| `#959FA7` | 浅灰 | 4% |
| `#C7C9D5` | 冷白 高光面 | 8% |
| `#F4F6F8` | 近白 最高光 | 9% |

**禁止**：不要用青色/蓝色的发光条、能量条、光效——鱼竿是**低科技工具**，发光是高科技武器才有的（见画风基准里的激光机枪）。

## 五、三把竿的差异

共用竿身（握柄、卷线器、导线环、钓线走向完全一致），只有竿尖不同：

| | 竿尖 |
|---|---|
| 基础鱼竿 | 只有一个**小金属顶环**（线从环中穿过后垂下） |
| 鱼竿刀 | **一片大号宽刃**（银白刃面 + 一道浅色刃口 + 深色刀箍包住竿尖），长度约竿身 1/3，刃朝右上 |
| 鱼竿锤 | **一个方形锤头**（深灰锤体 + 蓝灰锤面 + 一小块浅色饰块），宽度接近竿身粗细的 2 倍，用一小段锤箍连接竿尖 |

三把的竿尖配件都必须**牢牢接在竿身上**（有箍），不能悬空、不能错位。

## 六、直接可用的提示词（复制给绘图 AI）

### 通用前缀（三张都要带）

```
游戏物品图标，正侧视图，扁平矢量风格，纯色平涂，粗黑描边（外轮廓粗、内部细），
白色高光条在右上、深色硬阴影在右下，无渐变、无模糊、无透视、无发光效果。
纯白背景，无文字，水平横置、竿尖朝右，长宽比 2:1（建议出 1024×512 或更大）。
配色只用：#040507 描边、#1E212A 阴影、#323844 深灰、#4E5364 灰蓝主体、
#667588 灰蓝亮面、#959FA7 浅灰、#C7C9D5 冷白高光、#F4F6F8 近白。
```

### 1）基础鱼竿

```
画一根冰鹅族风格的钓鱼竿：细长竿身从握柄向上弯出弧线；
左下方是握柄 + 正圆形卷线器（中心轴点 + 侧面摇柄）；
竿身下沿挂 2 个侧视小导线环；
钓线从卷线器引出，依次穿过每个导线环的孔洞，到竿尖的小顶环后垂向右下方，末端一个小 J 形鱼钩。
不要弹匣、不要瞄准镜、不要发光。
```

### 2）鱼竿刀

```
同上（同一根竿身、同样的卷线器/导线环/钓线），
但在竿尖用一段深色刀箍接住一片大号宽刃：银白刃面 + 一道浅色刃口，刃身朝右上，长度约竿身 1/3。
最后一个导线环在刀的下方，钓线从它穿过后垂到右下的小鱼钩。
```

### 3）鱼竿锤

```
同上（同一根竿身、同样的卷线器/导线环/钓线），
但在竿尖用一段锤箍接住一个方形锤头：深灰锤体 + 蓝灰锤面 + 一小块浅色饰块，锤头宽度约为竿身的 2 倍。
最后一个导线环在锤头的下方，钓线从它穿过后垂到右下的小鱼钩。
```

## 七、历史踩坑清单（请避免这些）

| 问题 | 表现 |
|---|---|
| 钓线不穿环 | 线从导线环外面绕过去 / 线断开 / 线太细看不见 |
| 导线环方向错 | 画成正面看到的大圆环（应该侧视，窄长小环） |
| 配件没接住 | 刀/锤悬在竿尖旁边，没有刀箍/锤箍 |
| 环的位置错 | 最后一个导线环跑到配件上方或旁边 |
| 画风跑偏 | 出现了渐变、柔和阴影、写实渲染、透视 |
| 多余元素 | 鱼竿上出现雪花、发光条、能量槽、弹匣、瞄准镜 |
| 比例失衡 | 竿身太短（缩到图标里只剩一半宽度）、鱼钩垂得太低 |

## 八、交付规格

- **格式**：PNG，透明背景（或纯白背景）
- **尺寸**：单张 ≥ 1024×512（长宽比 2:1），我们后续会自己缩到 512×256
- **构****：主体占画面宽度 90% 以上，四周留一点边距
- **命名**：`FishingRod.png` / `AdvancedRodBlade.png` / `AdvancedRodHammer.png`

## 九、验收自查（画完对照一遍）

1. 缩到 128×64 还能一眼看出是"钓鱼竿"吗？
2. 钓线是不是真的穿过了每一个导线环？
3. 刀/锤是不是牢牢接在竿尖上？
4. 有没有出现任何发光/渐变/透视？
5. 颜色是不是只用了上面 8 个色？
