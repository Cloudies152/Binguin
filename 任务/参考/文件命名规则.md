# 文件命名规则

> 「看不懂哪个文件是哪个」——大部分是因为 **RimWorld 的文件名是路径驱动的**：
> 文件名不是随便取的，**游戏靠文件名去代码里找它**。改一个字就找不到。

---

## 一、贴图的方向后缀（最常见）

小人、服装贴图一律按**朝向**分文件，后缀固定这三个：

| 后缀 | 朝哪 |
|---|---|
| `_south` | 正面（朝屏幕下方） |
| `_north` | 背面 |
| `_east` | 朝右 |

> ★ **`_west`（朝左）不用做** —— 游戏自动把 `_east` 镜像过去。

**例**：
```
BinguinBody_Female_south.png     ← 女性体型的正面
BinguinBody_Female_north.png     ← 女性体型的背面
BinguinBody_Female_east.png      ← 女性体型的右侧
```

---

## 二、服装的体型后缀

服装贴图在方向**前面**还要加体型：

```
Tribalwear_Female_south.png   ← 女性体型的常服·正面
Tribalwear_Thin_south.png     ← 纤细体型的常服·正面
Tribalwear_Thin_north.png     ← 纤细体型的常服·背面
```

完整格式：`<名字>_<体型>_<方向>.png`

| 体型名 | 对应游戏里的 |
|---|---|
| `Female` | 女性 |
| `Thin` | 纤细 |
| `Male` | 男性 |
| `Fat` / `Hulk` | 胖 / 壮（本 Mod 用不到） |

---

## 三、XML 里的"贴图路径"和实际文件的关系

这是最容易搞混的地方。举例：

XML 里写（注意是**斜杠**分隔、**不带扩展名**）：
```xml
<texPath>Things/Building/Joy/Binguin/Band_Guitar</texPath>
```

对应磁盘上的文件（**反斜杠**是 Windows 的显示方式，实际是同一个路径）：
```
Textures/Things/Building/Joy/Binguin/Band_Guitar.png
└──┬───┘
   └── ★ 「Textures」这一层是自动加的，XML 里不写
```

**规则**：
```
XML 里的路径  =  Textures 后面的部分，去掉 .png
实际文件路径  =  Textures/ + XML 里的路径 + .png（或 _south.png 等方向后缀）
```

再一个例子，带方向后缀的：
```xml
<graphicPath>Races/Binguin/Head/BinguinHead</graphicPath>
```
实际文件：
```
Textures/Races/Binguin/Head/BinguinHead_south.png
Textures/Races/Binguin/Head/BinguinHead_north.png
Textures/Races/Binguin/Head/BinguinHead_east.png
```

## 四、★ 子目录也有自己的 `Textures`（最坑的一个）

这个仓库里有**两个** `Textures` 目录：

| 位置 | 管什么 |
|---|---|
| `Textures/`（根目录） | 大部分内容：人物、建筑、服装、武器、UI |
| `AdvancedFishing/Textures/` | **钓鱼子模块**：钓竿、配件、装配台、蟹笼、打窝用具 |

**同名文件可以同时存在于两处**，互不干扰。所以「尚方宝剑」的贴图在**子模块**里：

```
AdvancedFishing/Textures/Things/Item/Equipment/WeaponMelee/Binguin/VoidSwordFish.png
└────────┬────────┘
   注意这一层！不是根 Textures
```

> 放错到根 `Textures/` 就**加载不到**（因为 `LoadFolders.xml` 把 `AdvancedFishing/` 单独挂载）。

## 五、代码里引用的图标（特殊）

还有一类贴图**不是 XML 指定的**，而是 **C# 代码里硬找的**：

```csharp
makeBait.icon = ContentFinder<Texture2D>.Get("UI/Commands/BinguinMakeBait", false);
```

对应的文件是：
```
Textures/UI/Commands/BinguinMakeBait.png
```

这类**没有方向后缀、没有体型后缀**，就是一张方图（一般 64×64）。

## 六、`Defs/` 里的 XML 文件命名

`Defs/` 下的 XML 按**内容类别**分文件，名字是给人看的（游戏不靠 XML 文件名找东西，靠里面的 `<defName>`）：

| 文件名 | 装什么 |
|---|---|
| `Race_Binguin.xml` | 种族本体定义 |
| `Faction_Binguin.xml` | 派系 |
| `PawnKinds_Binguin.xml` | 单位模板（外交官、士兵、商人…） |
| `Weapons_Binguin.xml` `Weapons2_…` `Weapons4_…` | 武器（分了几个文件） |
| `Armor_Binguin.xml` | 护甲、头盔 |
| `Coats_Binguin.xml` | 大衣 |
| `Uniforms_Binguin.xml` | 职业装 |
| `Headwear_Binguin.xml` | 头饰（雪花绒帽、绒羽头冠、红围巾） |
| `Buildings_Binguin.xml` `Buildings2_…` | 建筑、家具 |
| `Research_Binguin.xml` | 科技树 |
| `Genes_Binguin.xml` | 基因 |
| `Floors_Binguin.xml` | 地板 |
| `Thoughts_Binguin.xml` | 心情 |
| `FacialAnimation_Binguin.xml` | 面部动画分层 |
| `Head_Binguin.xml` | 头型 |

> `<defName>` 才是真正的唯一 ID（比如 `Binguin_FishingRod`），
> XML 文件名只是方便人找。

## 七、`Source/` 里的 C# 文件命名

**前缀表示它是什么类型的东西**（RimWorld / Harmony 的惯例）：

| 前缀 | 意思 | 例子 |
|---|---|---|
| `Comp_` | 组件（挂在物品/建筑上的行为） | `Comp_BinguinRodAssembly.cs` |
| `JobDriver_` | 小人执行某个工作的过程 | `JobDriver_BinguinAssembleRod.cs` |
| `WorkGiver_` | 决定"谁该去干这个活" | `WorkGiver_BinguinPondFishing.cs` |
| `JoyGiver_` | 决定"空闲时去玩什么" | `JoyGiver_BinguinPondFishing.cs` |
| `Ability_` | 技能 | `Ability_BinguinRodSkills.cs` |
| `Dialog_` | 弹窗界面 | `Dialog_BinguinRodStockPick.cs` |
| `Patch_` / `HarmonyPatches_` | 改原版行为的补丁 | `Patch_BinguinPlayerRecruit.cs` |
| `Compat_` | 兼容别的 Mod | `Compat_BinguinSkinAndFace.cs` |
| `GameComponent_` | 全局状态（存档里跟着走） | `GameComponent_BinguinDiplomacy.cs` |
| `BinguinDefPatches.cs` | ★ 启动时把自定义类型挂到 XML 上的总入口 | — |

## 八、语言文件

```
Languages/ChineseSimplified/Keyed/Binguin.xml     ← 中文词条
Languages/English/Keyed/Binguin.xml               ← 英文词条
Languages/English/DefInjected/<类型>/BinguinTranslation.xml  ← 英文的物品名/说明
```

| 目录 | 给谁用 |
|---|---|
| `Keyed/` | C# 代码里 `"某个键".Translate()` 找的文字 |
| `DefInjected/` | 覆盖 XML 里 `<label>` / `<description>` 的文字 |

> 文件名不重要，**里面的 `<键名>` 才是关键**。中英两个文件的键必须**一一对应**。

---

## 一句话总结

| 你想找… | 去哪找 |
|---|---|
| 某个东西的**贴图** | 先在 `Defs/*.xml` 里搜它的 `<defName>`，看它的 `<texPath>` 是什么 |
| 某个东西的**数值/属性** | 同上，那个 XML 里 |
| 某个东西的**文字** | `Languages/<语言>/Keyed/Binguin.xml` 里搜中文 |
| 某个**功能怎么实现的** | `Source/` 里按前缀找（见上面第七节） |
