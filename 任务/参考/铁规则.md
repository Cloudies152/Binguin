# ⛔ 铁规则 —— 这 5 条违反了会直接弄坏 Mod

> 都是**已经踩过**的坑。改之前花 2 分钟看完，比改完 debug 两小时划算。

---

## ⛔ ① XML 里绝对不能出现本 Mod 的 C# 类型名

**不要**在任何 `Defs/*.xml` 里写这样的东西：

```xml
<!-- ❌ 千万不要 -->
<comps>
  <li Class="Binguin.Comp_BinguinRodAssembly">
    <compClass>Binguin.Comp_BinguinRodAssembly</compClass>
  </li>
</comps>

<!-- ❌ 也不要 -->
<thingClass>Binguin.Thing_BinguinSomething</thingClass>
<workerClass>Binguin.WorkGiver_Xxx</workerClass>
<driverClass>Binguin.JobDriver_Xxx</driverClass>
<giverClass>Binguin.JoyGiver_Xxx</giverClass>
```

### 为什么

HAR（外星人框架）的加载顺序会让这些类**在 XML 解析时还不存在**，游戏直接报红字、Mod 加载失败。

### 那本 Mod 的自定义组件是怎么挂上的？

**全部**由 `Source/BinguinDefPatches.cs` 在**运行时注入**：

```csharp
// [StaticConstructorOnStartup]，游戏启动、def 全部加载完之后才跑
// 遍历载入的 def，用 SafePatch 把 compClass / workerClass / … 填进去
```

> ★★ **所以你在 XML 里看不到自定义类型名 —— 那是故意的，别"帮忙补上"。**

### 那我想加一个新的自定义行为怎么办？

1. 先在 XML 里写**原版**类型（或干脆不写 comps）
2. 再到 `Source/BinguinDefPatches.cs` 里加一段运行时注入
3. 参考文件里已有的 `SafePatch` 调用

## ⛔ ② 不要用 `Harmony.PatchAll`

```csharp
// ❌ 在本 Mod 里会崩
harmony.PatchAll();
```

本 Mod 用的是**显式 `SafePatch`**（见 `Source/BinguinMod.cs` 与各 `Patch_*.cs`），
每个补丁单独指定目标方法 + 找不到时的降级处理。

**也**用 `[HarmonyPatch]` 特性类 + `PatchAll`。老老实实：

```csharp
MethodInfo target = AccessTools.Method(typeof(SomeType), "SomeMethod");
if (target == null)
{
    Log.Warning("[冰鹅族] 未找到 XXX，补丁未挂载");
    return;                       // ★ 找不到就降级，不要抛异常
}
harmony.Patch(target, new HarmonyMethod(prefix), new HarmonyMethod(postfix));
```

## ⛔ ③ 不要"顺手补全"贴图

[贴图需求总表](贴图需求总表.md) 里有一类叫 **「借原版」**：

| 冰鹅族的东西 | 借的原版贴图 |
|---|---|
| 冰鹅族风雪大衣 | `Things/Pawn/Humanlike/Apparel/Parka/Parka` |
| 冰鹅族头盔 | `.../AdvancedHelmet/AdvancedHelmet` |
| 各种子弹 | `Things/Projectile/Bullet_Small` |
| 臭鱼罐头炮弹 | `Things/Projectile/ShellTox` |

这些是**故意**让冰鹅族的东西长得和原版一样 —— **不是缺图**。

**看到"借原版"就去画一张，反而是错的。** 只画标了「缺图」「占位图」的。

## ⛔ ④ 不要改数值 / 玩法平衡

**改动这些之前必须先问作者**：

- 伤害、护甲、耐久、造价、工作量
- 概率（掉率、袭击概率、钓鱼概率…）
- 科技花费、研究点数
- 单位点数、袭击编成

**可以随便改**：

- 贴图
- UI 排版 / 文案
- 注释、文档
- 代码结构（重构，只要行为不变）

> 改数值前问一句，成本很低；改坏了玩家存档崩了，成本很高。

## 附：给程序员的额外提醒

### `Translate()` 返回的不是 `string`

```csharp
// ❌ 编译报 CS0172（TaggedString 与 string 无法互转）
Messages.Message("Binguin_Xxx".Translate(), MessageTypeDefOf.NeutralEvent);
Log.Message("..." + (cond ? "Binguin_Xxx".Translate() : otherString));

// ✅ 加 .ToString()
Messages.Message("Binguin_Xxx".Translate().ToString(), MessageTypeDefOf.NeutralEvent);
```

### C# 版本是 5（`csc.exe` 自带的那版）

```csharp
// ❌ 都不能用
var s = $"{a} 和 {b}";                    // 字符串插值（C# 6）
public int X => 1;                        // 表达式体成员（C# 6）
var y = obj?.Prop;                        // 空条件运算符（C# 6）
```

用 `string.Format` / `+` 拼接，老式写法。

### 改完必须重启游戏

C# 是**编译成 DLL** 的，游戏运行中改了不生效。改完：

```powershell
cd Source
.\build.ps1
```

然后**完全退出游戏再启动**。看日志确认：
```
%USERPROFILE%\AppData\LocalLow\Ludeon Studios\RimWorld by Ludeon Studios\Player.log
```

```csharp
// ✅ 第二个参数 false = 找不到就返回 null，不报错
Texture2D icon = ContentFinder<Texture2D>.Get("UI/Commands/Xxx", false);
```
