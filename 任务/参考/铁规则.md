# 协作规则与已知问题

> 区分实际错误与实现选择；历史结论以当前代码和可复现证据为准。

## ① 自定义类型直接在 XML 声明

自定义 Comp、Worker、JobDriver 等使用完整命名空间和程序集名。`Class` 指定属性对象类型，`compClass` 指定组件行为类型，二者不要混用。

```xml
<li Class="Binguin.Feature.Rods.CompProperties_BinguinRodAssembly, Binguin" />
<driverClass>Binguin.Feature.Rods.JobDriver_BinguinAssembleRod, Binguin</driverClass>
```

原先“XML 禁止自定义类型、HAR 加载顺序使类型不存在”的结论已废弃。原版加载流程在 XML 前加载程序集，程序集限定名也不依赖自定义类型是否进入 `AllTypes` 缓存。

新增行为时直接配置对应功能的 XML；可选 DLC/mod 内容用 `MayRequire` 或加载根门控。出现类型解析错误时检查命名空间、DLL 产物和依赖加载异常，不添加占位类型加启动替换，也不清理类型缓存。

`BinguinDefPatches` 已删除。原版共享 Def 的调整使用按功能分类的标准 XML Patch。详见 [XML 类型与依赖](../../Source/XML_DEFS.md)。

## ② Harmony 注册方式按实际需求选择

允许使用 `[HarmonyPatch]` 和 `PatchAll`。它们是 Harmony 的标准注册方式；“本项目一用就崩”没有可复现证据，不作为禁令。

遇到同名重载时明确指定参数类型，例如：

```csharp
[HarmonyPatch(typeof(Verse.AI.Pawn_PathFollower), "CostToMoveIntoCell",
    new Type[] { typeof(Verse.Pawn), typeof(Verse.IntVec3) })]
```

需要动态寻找目标时可用 `TargetMethod` / `TargetMethods`；可选目标在 `Prepare` 中检查是否存在。补丁参数须匹配原方法参数名，或用 Harmony 支持的参数映射。重载歧义和参数名错误都应修正目标声明，不能归咎于 `PatchAll`。

当前项目保留显式注册和逐条异常日志，入口包括 `Source/Binguin/Patch/HarmonyPatches_Binguin.cs` 及各功能的初始化类。这是现有实现，不是永久限制。改用自动注册前须移除同一补丁的手动注册，检查历史特性类是否应启用，并明确传入程序集，避免重复执行或误启用补丁。若需要隔离每个类的注册失败，可逐类调用 `CreateClassProcessor(type).Patch()`。

参考 [Harmony 官方特性说明](https://harmony.pardeike.net/v2/articles/annotations.html)。

## ⛔ ③ 不要"顺手补全"贴图

[贴图需求总表](贴图需求总表.md) 里有一类叫 **「借原版」**：

| 冰鹅族的东西 | 借的原版贴图 |
|---|---|
| 冰鹅族风雪大衣 | `Things/Pawn/Humanlike/Apparel/Parka/Parka` |
| 冰鹅族头盔 | `.../AdvancedHelmet/AdvancedHelmet` |
| 各种子弹 | `Things/Projectile/Bullet_Small` |
| 臭鱼罐头炮弹 | `Things/Projectile/ShellTox` |

这些是**故意**让冰鹅族的东西长得和原版一样 —— **不是缺图**。

**看到"借原版"就去画一张，反而是错的。** 只画标了「缺图」「占位图」的。

## ⛔ ④ 不要改数值 / 玩法平衡

**改动这些之前必须先问作者**：

- 伤害、护甲、耐久、造价、工作量
- 概率（掉率、袭击概率、钓鱼概率…）
- 科技花费、研究点数
- 单位点数、袭击编成

**可以随便改**：

- 贴图
- UI 排版 / 文案
- 注释、文档
- 代码结构（重构，只要行为不变）

> 改数值前问一句，成本很低；改坏了玩家存档崩了，成本很高。

## 附：给程序员的额外提醒

### `Translate()` 返回的不是 `string`

```csharp
// ❌ 编译报 CS0172（TaggedString 与 string 无法互转）
Messages.Message("Binguin_Xxx".Translate(), MessageTypeDefOf.NeutralEvent);
Log.Message("..." + (cond ? "Binguin_Xxx".Translate() : otherString));

// ✅ 加 .ToString()
Messages.Message("Binguin_Xxx".Translate().ToString(), MessageTypeDefOf.NeutralEvent);
```

### C# 版本是 5（`csc.exe` 自带的那版）

```csharp
// ❌ 都不能用
var s = $"{a} 和 {b}";                    // 字符串插值（C# 6）
public int X => 1;                        // 表达式体成员（C# 6）
var y = obj?.Prop;                        // 空条件运算符（C# 6）
```

用 `string.Format` / `+` 拼接，老式写法。

### 改完必须重启游戏

C# 是**编译成 DLL** 的，游戏运行中改了不生效。改完：

```powershell
cd Source
.\build.ps1
```

然后**完全退出游戏再启动**。看日志确认：
```
%USERPROFILE%\AppData\LocalLow\Ludeon Studios\RimWorld by Ludeon Studios\Player.log
```

### 没贴图时用 `false` 参数，别让它抛异常

```csharp
// ✅ 第二个参数 false = 找不到就返回 null，不报错
Texture2D icon = ContentFinder<Texture2D>.Get("UI/Commands/Xxx", false);
```
