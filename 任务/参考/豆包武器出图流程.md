## 一、给豆包的提示词公式

```
直接出图（不要给建议）。参考图：
图1 = 结构参考（原型像素图/别的枪）—— 只取形状与比例
图2 = 画风参考（我们现有的枪，如 Shotgun/LaserGatling）—— 取配色与画法
要求：
1）结构：<逐条写清比例和部件位置，能给数字就给数字>
2) 图案：<徽记/花纹，写清形状、是否要描边、大小占比>
3) 画风：白顶面板 + 中灰蓝壳体 + 结构蓝 + 冰蓝能量 + 粗黑描边，扁平矢量、纯色平涂、无渐变
4) 侧视、枪口朝右、纯白背景、无文字、256×128 比例
```

### 提示词要点

| 要点 | 说明 |
|---|---|
| **给数字** | 「长宽比 2.9:1」「炮管高度 = 炮身 85%」比「长一点/粗一点」有效得多 |
| **一次只改 1~2 处** | 改多了 AI 会重画整个构图 |
| **先量原型** | 用脚本量出原型的 bbox/各色块 bbox，把比例直接写进提示词 |
| **明确禁止项** | 「不要长镜筒」「不要垂直握把」「不要多余弧线」要写出来 |
| **画风基准图** | 必须给一张我们自己的成品图，否则风格会飘 |

## 三、后处理（Python，必须做）

```python
1. 去白底      flood fill 边界近白像素（tol≈24）→ alpha=0
2. 取最大连通域  cv2.connectedComponentsWithStats → 去掉右下角"豆包AI生成"水印
3. 裁切+缩放    bbox 裁切 → 等比缩放到 256×128（留 6px 边距）
4. 量化        cv2.kmeans 到 10~12 色 → 消除 AI 的软过渡，得到硬边平涂
5. 统一外描边   mask 内圈侵蚀 2px 填黑 → 粗细均匀的连续外轮廓
6. 锐化        UnsharpMask(radius=1.2, percent=90)
```

**为什么必须量化**：AI 出图边缘有渐变，缩到 256 会糊；kmeans 量化后变成纯色块，清晰度立刻回来。

**为什么必须重描外轮廓**：AI 画的外轮廓粗细不均；用「mask 减 erosion」整圈填黑最稳。

## 四、细节图案（如企鹅脸）建议代码画

AI 画徽记时大小/描边很难精确控制，建议：
1. 让 AI 出**没有徽记**的版本
2. 用 Pillow 按需要精确绘制：

```python
r = hh*0.98/2                      # 直径 = 炮身高度（上下相切）
d.ellipse([cx-r,cy-r,cx+r,cy+r], outline=(20,20,22,255), width=1)  # 细描边
d.ellipse([cx-r+2,cy-r+2,cx+r-2,cy+r-2], fill=(251,251,252,255))
# 眼睛：黑圆 + 白色高光点；喙：橙色三角
```

可复用脚本：`任务/参考/绘制企鹅脸.py`

## 五、验收清单

- [ ] 结构比例和原型对得上（缩到 64px 还能认出来）
- [ ] 配色占比接近 DP-12：白 11% / 中灰 52% / 深灰 21% / 黑 16% / 蓝 20%
- [ ] 外轮廓粗细均匀、只有一圈
- [ ] 无渐变、无混色、无脏边
- [ ] 纯白背景已去掉（透明）
