## 一、先搞清两类语言文件

| 类型 | 目录 | 管什么 | 键长什么样 |
|---|---|---|---|
| **Keyed** | `Languages/<语言>/Keyed/Binguin.xml` | C# 代码里的界面文字、对话、信件 | `<Binguin_Xxx_01>文字</Binguin_Xxx_01>` |
| **DefInjected** | `Languages/<语言>/DefInjected/<def类型>/*.xml` | 覆盖 XML 里物品的 `<label>` / `<description>` | `<Binguin_FishingRod.label>文字</…>` |

**Keyed** = 代码里这样找的：
```csharp
string s = "Binguin_CompRodAssembly_01".Translate();
```

**DefInjected** = 覆盖 def 的字段，键的格式是 `defName.字段路径`：
```xml
<Binguin_FishingRod.label>量产型钓竿</Binguin_FishingRod.label>
<Binguin_AbilityPierce.description>直钩：获得技能「穿刺」…</Binguin_AbilityPierce.description>
```

## 二、加一个新语言（比如日文）

### 步骤

```bash
# 1. 复制整个英文目录
cp -r Languages/English Languages/Japanese

# 2. 改语言声明（每个 xml 顶部的 <LanguageData> 里如果有 <language> 字段就改）
# 3. 翻译 Keyed/Binguin.xml 与 DefInjected/ 下所有文件
# 4. 提交
```

### ★★ 三条铁律

**① 键名一个字都不能改。**

```xml
<!-- ❌ 错的：把键也翻译了 -->
<冰鹅族_钓竿_01>量産型釣り竿</冰鵝族_钓竿_01>

<!-- ✅ 对的：只改值 -->
<Binguin_CompRodAssembly_01>量産型釣り竿</Binguin_CompRodAssembly_01>
```

**② 占位符 `{0}` `{1}` 必须原样保留。**

```xml
<!-- 中文原文 -->
<Binguin_Band_Arrived>冰鹅族乐队和 {0} 位观众正从地图边缘赶来！</Binguin_Band_Arrived>

<!-- ✅ 日文：{0} 保留，位置可以按语序调整 -->
<Binguin_Band_Arrived>ビングインの楽団と観客 {0} 名がマップ端から到着しました！</Binguin_Band_Arrived>

<!-- ❌ 错的：删了 {0} 或者写成 {0 】
```

> `{0}` 是运行时填进去的数字/名字。删了就变成空白，或多打印一个花括号。

**③ 字面 `\n` 要保持是 `\n`（两个字符），不要写成真换行。**

```xml
<!-- ✅ 对：\n 是两个字符（反斜杠 + n），游戏会渲染成换行 -->
<Binguin_Xxx>第一行\n第二行</Binguin_Xxx>

<!-- ❌ 错：这里敲了真的回车，游戏会显示成多余的空格/乱掉 -->
<Binguin_Xxx>第一行
第二行</Binguin_Xxx>
```

## 四、怎么确认没翻错

### 键是否一一对应

中英两个 `Keyed/Binguin.xml` 的**键集合必须完全一样**（603 : 603）。

用浏览器就能粗查：两个文件各搜 `<Binguin_`，比较数量。或者本地：

```powershell
# 数键个数（两边应该一样）
(Select-String -Path Languages\ChineseSimplified\Keyed\Binguin.xml -Pattern '<Binguin_' ).Count
(Select-String -Path Languages\English\Keyed\Binguin.xml -Pattern '<Binguin_' ).Count
```

### 占位符是否漏掉

```powershell
# 找出所有含 {0} 的键，人工核对两边都有
Select-String -Path Languages\English\Keyed\Binguin.xml -Pattern '\{\d+\}'
```

## 五、常见问题

**Q：改文案要重新编译吗？**
不用。语言文件是 XML，游戏启动时读取。**改完重启游戏即可**（不用重编 DLL）。

**Q：为什么有些中文不能翻译？**
代码里 `Log.Message(...)` 之类的**开发者日志**、`[DebugAction]` 的**调试菜单**故意保留中文 ——
玩家看不到，翻了没意义。

**Q：物品名（`<label>`）在哪改？**
在 `DefInjected/`，不在 Keyed。格式 `<DefName.label>文字</DefName.label>`。
中文那边直接写在 `Defs/*.xml` 里的 `<label>` 就是中文。

**Q：我想加中文里没有的新词条？**
那要同时改 C# 代码（加 `.Translate()` 调用），属于程序任务。见 [程序任务.md](程序任务.md)。
